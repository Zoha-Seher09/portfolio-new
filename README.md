# My Portfolio Website

A personal portfolio website built with Flask, showcasing my skills, education, experience, certifications, projects, services, and testimonials.

## ✨ Features
- Skills section
- Education timeline
- Work experience
- Certifications with credential links
- Projects showcase
- Services offered
- Testimonials (with live submission form)
- Contact form
- Dark mode toggle

## 🛠️ Built With
- Python
- Flask
- HTML/CSS
- Jinja2 templating

## 🚀 How to Run Locally

1. python app.py
2. Open http://127.0.0.1:5000
